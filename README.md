## ✅ Setup Checklist (Do These Before Going Live)

### 1. Formspree (Booking Emails)
- Go to [formspree.io](https://formspree.io) → sign up free
- Create a new form → enter your email `plusphonerepair2@gmail.com`
- Copy your Form ID (looks like `xpzgabc1`)
- In `index.html`, search for `YOUR_FORM_ID` and replace both instances with your real ID

### 2. Google Review Link
- Go to your Google Business Profile
- Click **Ask for reviews** → copy the review link
- In `index.html`, search for `YOUR_GOOGLE_PLACE_ID` and replace it

### 3. OG Image (Social Share Preview)
- Create a 1200×630px image of your shop or logo
- Name it `og-image.jpg`
- Upload it to this repo alongside `index.html`

## 🚀 How to Deploy (Netlify)
1. Go to [netlify.com](https://netlify.com) → log in
2. Drag this entire folder onto the deploy area
3. Your site updates instantly

## 🚀 How to Deploy (GitHub Pages — Free)
1. Go to repo **Settings** → **Pages**
2. Source: `Deploy from branch` → `main` → `/ (root)`
3. Save — your site goes live at `https://yourusername.github.io/paradise-phone-repair`
4. Then connect your custom domain `paradisephonerepair.com`
